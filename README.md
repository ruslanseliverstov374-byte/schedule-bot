# 🎓 Бот расписания Поволжского ГУФКСиТ (Казань)

Telegram-бот, который показывает студентам **актуальное расписание прямо с официального
сайта** [timetable.unifirst.ru](https://timetable.unifirst.ru/), ведёт общую базу домашних
заданий группы и напоминает о парах и дедлайнах.

Написан на **чистом Python без единой зависимости**: ни `pip install`, ни виртуальных
окружений. Данные — в SQLite. Запускается и на Windows в один клик, и на VPS круглосуточно.

---

## 1. Быстрый старт (3 минуты)

1. **Получите токен бота.** В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot`
   → придумайте имя → скопируйте токен вида `8123456789:AAH...`
2. **Запустите `setup.bat`** (двойной клик) — он спросит токен, проверит связь с сайтом
   расписания и запустит бота.
3. **Откройте бота в Telegram** и нажмите `/start`. Бот попросит выбрать группу —
   достаточно написать её номер, например `26281`.

Ручной запуск:

```bash
cd schedule-bot
python bot.py --token 8123456789:AAH...
```

Токен можно хранить в `token.txt`, в переменной окружения `BOT_TOKEN` или в `.env`
(образец — `.env.example`). Требуется Python 3.9+ (проверено на 3.14); интернет нужен
только исходящий.

## 3. Откуда берётся расписание и как проверяется актуальность

Сайт расписания `timetable.unifirst.ru` — это JS-приложение: в HTML нет ни таблиц, ни
расписания, данные подгружает скрипт. Бот обращается напрямую к тому же публичному API,
которым пользуется сайт:

```
GET https://api.unifirst.ru/api/v1/groups?limit=500
GET https://api.unifirst.ru/api/v1/timetable?title=26281&week=41&year=2026
Заголовок: api-key: 777e5031c257a3d5ce7aa54aa56015cb
```

Подробное описание протокола — [docs/API.md](docs/API.md).

**Онлайн-проверка актуальности** работает так:

1. Каждые **20 минут** (настраивается `--refresh-minutes`) бот сам запрашивает расписание
   текущей и следующей недели для всех групп, на которые кто-то подписан.
2. Новый ответ сравнивается с сохранённым по «отпечатку» пар.
3. Если что-то изменилось — бот пишет подписчикам группы, что именно поменялось:

```
⚠️ Расписание изменилось
Группа 26281

Неделя с 05.10 по 11.10 2026 года
➖ Понедельник, 5 октября: История России · 10:10 · E703
➕ Вторник, 6 октября: Плавание · 08:30 · Бурев бассейн
🔁 Среда, 7 октября: Анатомия человека (аудитория: D101)
```

4. Кнопка **🔄 Обновить** делает то же самое немедленно и показывает результат лично вам.
5. Если сайт недоступен, бот отдаёт последнюю сохранённую версию и честно предупреждает:
   *«📴 Показал сохранённую копию — сейчас нет связи с сайтом расписания»*.

## 4. Домашние задания

ДЗ вуз в расписании не публикует, поэтому их ведёт сама группа — зато с удобными
напоминаниями.

**Добавить задание** → 📝 ДЗ → «➕ Добавить ДЗ» → выбрать, куда:

* **📘 В общую базу группы** — увидят все одногруппники;
* **🗒 Личная заметка** — видите только вы.

Дальше одним сообщением:

```
предмет | задание | срок
```

Примеры:

```
История | §§1-2, вопросы 3-5 | 08.10
Русский | упражнение 45 | завтра
Анатомия | выучить мышцы спины | пятница
```

Срок понимается как `08.10`, `8.10.2026`, `2026-10-08`, `сегодня`, `завтра`, `послезавтра`,
`через 3 дня`, `пн`, `ср`, `пт`. Можно указать и четвёртое поле — преподавателя.

**Ещё способы:**

* В расписании на день есть кнопка **«📝 ДЗ по предмету»** — предмет, преподаватель и
  аудитория подставятся сами, нужно написать только задание.
* Кнопка **👍 Подтвердить** на общем задании = «я тоже это записал».
* **✔️ Выполнено** — закрыть задание (общее задание может закрыть автор или админ).
* **🗑 Удалить** — убрать своё задание.

## 5. Напоминания

| Напоминание | Когда приходит | Настройка |
|---|---|---|
| 🌙 Вечерний дайджест | В выбранное время (по умолчанию 20:00 по Казани): пары на завтра и что сдать | ⏰ Напоминания → 🌙 / 🕒 |
| 🔔 Перед парой | За 15, 30 или 60 минут до начала пары: предмет, время, аудитория, преподаватель | ⏰ Напоминания → 🔔 |
| 📣 Изменения расписания | Сразу, как только сайт отдал другое расписание | ⏰ Напоминания → 📣 |
| 📚 Дедлайны ДЗ | Утром в день сдачи — что нужно сдать сегодня | ⏰ Напоминания → 📚 |

Дубли исключены: каждое напоминание отправляется один раз (журнал отправок в базе).
Часовой пояс — UTC+3 (Казань), переходов на летнее время в России нет.

## 6. Проверка и тесты

```bash
python bot.py --check          # связь с API, база, разбор дат и ДЗ (без Telegram)
python tests/simulate.py       # полный офлайн-прогон: 50 проверок сценариев бота
python tests/test_mock_api.py  # самопроверка офлайн-мока API: 46 проверок
check.bat                      # всё сразу на Windows
```

Посмотреть, как бот отвечает, можно без Telegram и без токена:

```bash
python tools/preview.py 26281                # экраны на живых данных группы
python tools/preview.py 26281 --save out.txt # то же в файл
```

Пример такого предпросмотра — [docs/preview-26281.txt](docs/preview-26281.txt).

`tests/simulate.py` поднимает локальный мок API и подменяет Telegram, поэтому проверяет
бот целиком без сети: онбординг и выбор группы, экраны «сегодня/завтра/неделя», поиск
группы с опечаткой (`262801` → подсказка `26281`), общую и личную домашки, подтверждения,
вечерний дайджест, напоминание перед парой, обнаружение изменения расписания и работу
из кэша, когда сайт недоступен.

Результат на момент сдачи:

```

ИТОГ: ВСЁ ЗЕЛЁНОЕ
```

## 7. Работа 24/7

### Вариант 1: бесплатное облако Render (0 ₽, компьютер не нужен) — уже развёрнуто

сервису заснуть. База сохраняется закреплённым сообщением в чате владельца и поднимается
после перезапуска. Пошагово: **[docs/FREE-24-7.md](docs/FREE-24-7.md)**.

Плюсы: 0 ₽, карта не нужна, работает без вашего компьютера, бот отвечает мгновенно
(режим вебхука). Минусы: 750 часов в месяц на аккаунт, сервис засыпает без пинга,
файловая система контейнера стирается при перезапуске (поэтому и нужны копии базы).

### Вариант 2: этот компьютер (0 ₽)

`install_autostart.bat` — создаёт задачу в планировщике Windows: бот стартует при входе
в систему и работает в фоне (окно консоли не появляется). Убирается
`remove_autostart.bat`. Минус: пока компьютер выключен или спит, бот молчит.

### Вариант 3: VPS (150–300 ₽/мес, без ограничений)

На сервере расписание проверяется всегда, даже когда ваш компьютер выключен.

```powershell
powershell -ExecutionPolicy Bypass -File deploy\deploy_to_vps.ps1 -Server <IP_СЕРВЕРА>
```

Скрипт упакует проект, скопирует его на сервер, поставит systemd-службу с автозапуском
и самопроверкой, перенесёт базу (если она есть) и покажет статус. Подробности, Docker и
решение проблем — [deploy/DEPLOY.md](deploy/DEPLOY.md).

## 9. Если что-то не работает

**Бот не отвечает.** Проверьте, что окно `run.bat` открыто, а в `logs/bot.log` нет
`Unauthorized` — это значит, что токен неверный: запустите `setup.bat` снова.

**«Сайт расписания не отвечает».** Сайт вуза мог быть недоступен или изменил API.
Бот продолжит показывать сохранённую копию. Проверьте связь: `python bot.py --check`.
Если API изменился, ключ и адреса ищутся заново скриптами `tools/probe.py` и
`tools/recon_api.py` (см. [docs/API.md](docs/API.md), раздел «Если API изменился»).

**Группа не находится.** Пишите только цифры: `26281`, а не `26281м` или `26-281`.
Если ошиблись на одну цифру (например `262801`), бот сам предложит похожие группы.

**«Занятий нет» на всю неделю.** Так ответил сайт: возможно, расписание ещё не
выложили или у группы эта неделя без пар. Проверьте на
[timetable.unifirst.ru](https://timetable.unifirst.ru/) — бот показывает ровно то же.

**Хочу перенести бота.** Скопируйте папку целиком (вместе с `data/bot.db` и `token.txt`).
База хранит группы, ДЗ и настройки пользователей.

## 10. Честные ограничения

* **ДЗ не приходят из вуза автоматически** — их вносит группа (это же и плюс: видно,
  кто что записал, и есть подтверждения).
* **Ключ доступа к API публичный**: он лежит в открытом JS-бандле сайта расписания.
  Если вуз его сменит — бот перестанет получать данные, ключ ищется заново по инструкции
  в [docs/API.md](docs/API.md).
* **Бот не официальный сервис университета** — это студенческий проект поверх открытых
  данных сайта.
* Расписание звонков (время пар) бот берёт из самого API: время начала и конца каждой
  пары приходит вместе с занятием.
